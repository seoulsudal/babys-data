BABYS(이하 "앱")는 육아 정보를 보여 주는 앱입니다. 앱은 입력하신 정보를 운영자의 서버로 보내지 않습니다. 아래에서 어떤 정보를 어떻게 다루는지 설명합니다.

1. 처리하는 정보

정보입력 방법쓰는 곳

2. 보관과 전송

  • 아이 정보, 성장 기록, 일상 기록(투약 약 이름, 체온, 병원 방문, 메모 포함), 내가 추가한 빠른 선택 글자, 즐겨찾기한 곳의 번호, 지금 보는 아이의 번호는 이 기기의 앱 내부 저장소(데이터베이스와 앱 설정 파일)에만 저장됩니다. 운영자나 제3자에게 전송하지 않습니다.
  • 여러 아이의 정보는 아이별로 따로 저장되며, 서로 섞거나 비교하지 않습니다.
  • 안드로이드의 자동 백업(클라우드 백업)과 기기 간 이전에서는 앱 데이터를 제외하도록 설정되어 있어, 새 기기로 저절로 옮겨지지 않습니다. 옮기려면 아래 백업 파일을 직접 만들어 옮기세요.
  • 백업 파일(사용자가 직접 만들고 옮기는 파일). 설정의 "백업 → 백업 파일 만들기"를 누르면 안드로이드의 저장 화면이 열리고, 사용자가 고른 위치에 파일이 만들어집니다. 이 파일에는 아이 별칭·생년월일과 기록이 암호화되지 않은 채 그대로 들어 있으므로 보관하고 공유할 때 주의하세요. 앱은 이 파일을 어디로도 보내지 않으며, 파일을 어디에 둘지(내 폰, 드라이브, 메일 등)는 사용자가 고릅니다. 복원은 사용자가 파일을 직접 고르고 "복원"을 눌렀을 때만 이루어지며, 이때 지금 기기의 기록이 모두 파일의 내용으로 바뀝니다(되돌릴 수 없습니다). 파일에 문제가 있으면 복원하지 않고 지금 기록을 그대로 둡니다. 백업 파일을 만들고 복원하는 동안 인터넷을 쓰지 않습니다.
  • 위치는 저장하지 않고 거리 계산에 쓴 뒤 버립니다. 앱은 처음 실행할 때 위치 권한을 한 번 묻고, 허용하면 키즈카페·나들이·달빛병원 탭과 홈의 장소 카드에서 가까운 순을 위해 위치를 확인합니다. 거절하면 가까운 순으로 보기를 누를 때 다시 묻습니다. 위치 권한은 "정확한 위치"와 "대략적인 위치" 중에서 사용자가 고르며, 대략적인 위치만 허용하면 거리가 실제와 수 km 달라질 수 있습니다. 이미 대략적인 위치만 허용한 경우에는 정확한 위치로 바꿀지 한 번만 묻습니다. 백그라운드(앱을 쓰지 않을 때)에서는 위치를 쓰지 않습니다. 권한을 거절해도 장소 목록은 계속 볼 수 있습니다.

3. 인터넷 사용

앱은 서울형 키즈카페 목록과 나들이(장소·행사) 목록, 달빛어린이병원 목록, 달빛병원 근처 약국 목록(모두 공개 데이터)을 내려받기 위해서만 인터넷을 씁니다. 나들이·달빛병원·약국 목록은 하루에 한 번쯤 새 파일이 있는지 확인하며, 자료는 한국관광공사(TourAPI)·서울 열린데이터광장(서울문화포털)·국립중앙의료원(전국 병·의원 찾기 서비스, 전국 약국 정보 조회 서비스)의 공개 자료를 모아 올린 것입니다.

  • 내려받을 때 아이 정보나 위치는 보내지 않습니다.
  • 파일을 제공하는 서버(GitHub Pages)에는 앱을 쓰는 기기의 IP 주소 등 일반적인 접속 기록이 남을 수 있습니다. 이는 서버 제공자가 처리하는 것으로, 앱이 따로 수집하거나 저장하지 않습니다.
  • 인터넷에 연결되지 않아도 앱에 포함된 목록으로 동작합니다.
  • 백업 파일 만들기·복원은 인터넷을 쓰지 않습니다.

4. 제3자 제공, 광고, 분석

제3자에게 정보를 제공하지 않으며, 광고·사용 통계 분석·충돌 보고 도구를 넣지 않았습니다.

5. 보관 기간과 삭제

  • 정보는 직접 지우시기 전까지 기기에 남습니다.
  • 앱 안에서 삭제: 오른쪽 위 설정 → "아이 관리" → 아이를 고르고 "삭제"(또는 홈의 "수정" → "아이 정보 삭제"). 그 아이의 성장 기록과 일상 기록이 함께 지워지고 다른 아이의 기록은 그대로입니다. 이름은 설정에서 언제든 바꿀 수 있습니다. 성장 기록 한 건은 기록 화면에서, 일상 기록 한 건(투약 약 이름 포함)은 홈의 오늘 기록이나 기록 탭에서 항목을 눌러 "이 기록 삭제"로 지웁니다. 즐겨찾기는 하트를 다시 눌러 끕니다.
  • 앱을 삭제하면 기기의 모든 앱 데이터가 지워집니다.
  • 백업 파일은 앱이 아니라 사용자가 고른 위치에 있으므로 앱 삭제나 앱 안의 삭제로는 지워지지 않습니다. 더 이상 필요하지 않으면 파일을 직접 지우세요.
  • 운영자는 사용자의 정보를 갖고 있지 않으므로, 별도의 삭제 요청 절차는 필요하지 않습니다.

6. 만 14세 미만 아동

앱은 부모·보호자가 아이의 정보를 보려고 쓰는 앱이며, 아이가 직접 쓰도록 만들어지지 않았습니다. 입력한 아이 정보는 위 2항처럼 기기 밖으로 나가지 않습니다.

7. 의료 정보가 아닙니다

앱의 월령별 안내, 예방접종·검진 일정, 성장 백분위는 참고용이며 진단·치료·상담을 대신하지 않습니다. 일상 기록의 합계와 횟수, 마지막 기록이 얼마 전인지는 직접 입력한 내용으로 계산한 숫자이며, 앱은 아이의 수면·수유 상태를 평가하거나 판단하지 않습니다. 투약 기록은 입력하신 약 이름을 그대로 적어 둘 뿐, 약의 용량·복용 방법·효과를 안내하거나 판단하지 않습니다. 약에 대한 궁금증은 의사나 약사와 상담하세요. 아이의 건강이 걱정되면 의료진과 상담하세요.

8. 데이터 출처

  • 예방접종·검진 일정: 질병관리청 예방접종관리과, 국민건강보험공단
  • 성장 백분위: 국민건강보험공단 성장 자료(공공데이터포털)
  • 서울형 키즈카페: 서울특별시 열린데이터광장 (공공누리 제1유형, 출처표시)

9. 정책 변경

내용이 바뀌면 이 문서를 고치고 시행일을 바꿉니다. 중요한 변경은 앱 업데이트 설명에 함께 적습니다.
